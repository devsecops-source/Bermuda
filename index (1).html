WHAT IT DOES
[VOICE]

Talk to it, or type. Bermuda answers from an offline knowledge base first, and falls back to Gemini online for anything else — using your own free API key, never one it ships with.

[CAMERA]

Draw in the air. Point your index finger at the webcam and Bermuda tracks your hand to let you paint on screen, in real time, fully offline.

[GAMES]

Snake, Tic-Tac-Toe, Number Guess, a drawing palette. Small offline games with adjustable difficulty, built right into the app.

[CALENDAR]

A real calendar. Click a day to add a reminder; Bermuda reads today's reminders back to you when it starts.

[PC TOOLS]

Your machine, at a glance. CPU, RAM, disk, maker and model, plus shortcuts into Device Manager, Disk Cleanup and more.

[SECURITY]

A basic file scanner. Flags double extensions and known-bad hashes, with an optional VirusTotal lookup — a helper, not a replacement for real antivirus.

BEFORE YOU INSTALL

Windows may warn you first

The installer isn't digitally signed yet — that costs money I haven't spent. Windows may show "protected your PC". Click More info → Run anyway. Source is on GitHub if you want to check it yourself first.

Camera & microphone are optional

Windows will ask permission for hand-drawing and voice. Nothing is recorded or sent anywhere — it's processed on your machine.

Online AI uses your own key

Chat beyond the offline knowledge base needs a free Gemini API key, which you add yourself in Settings. Bermuda never ships with one, and your key stays on your PC.

No ads, no tracking, no account

Nothing phones home. Everything Bermuda stores — settings, reminders, locked folders — lives in a folder on your own machine.

ABOUT

Bermuda is built and directed by Rao Orvah, a college student in Karachi, Pakistan, who learned Python to build it. It started as a small desktop assistant and grew from there, one feature at a time, with AI assistance for parts of the code.

It's a solo, zero-budget project — no company, no funding, just something built because it was interesting to build. If you run into a bug or want a feature, open an issue on GitHub.
